# Prompt Patterns

## Concept comparison

Generate each direction in a separate call while keeping the subject block identical.

```text
Use case: stylized-concept
Asset type: financial B2B product empty-state illustration, concept review
Primary request: Communicate without text that multi-source financial data retrieval and model evaluation completed, but the selected reporting period contains only a few valid behavior observations, so no meaningful statistic is displayed yet. This is neutral-positive and supports future periodic review.
Subject: An orderly report folder holding evaluated blank report sheets, a closed model-evaluation ring behind it, exactly three small data tokens entering aligned slots, a mostly unused segmented time arc, and a subtle forward-monitoring orbit.
Style/medium: <CONCEPT DIRECTION A, B, OR C FROM style-system.md>
Composition/framing: Centered isolated object cluster, front three-quarter view, generous clear margin, readable at 240 by 240 pixels.
Color palette: Brand blue #326FF7, white, pale blue, with cyan #43D7E8 used only as a tiny accent.
Lighting/mood: Calm, orderly, capable, gently anticipatory; soft cool contact shadow.
Background: genuinely transparent RGBA, including all four corners.
Constraints: same subject and complexity across concept directions; intact completed process; visibly sparse but not completely empty.
Avoid: all text, letters, numerals, currency symbols, logos, watermark, people, mascots, red, warning signs, crosses, exclamation marks, locks, 404, rejection, broken equipment, severed paths, downward charts, opaque backdrop, scenery, decorative plants.
```

## Production asset

```text
Use case: stylized-concept
Asset type: financial B2B product empty-state transparent illustration
Primary request: <FOUR-PART MEANING FROM SKILL.md, adapted only to the supplied business dimension>
Subject: <ONE MAIN OBJECT>, <ONE OR TWO SUPPORTING OBJECTS>, <EXACT SPARSE EVIDENCE>, <SUBTLE FUTURE-MONITORING CUE>.
Style/medium: <APPROVED PRODUCTION STYLE ANCHOR verbatim>
Composition/framing: centered isolated cluster; square footprint; approved camera and negative-space margin; readable at 240 by 240 pixels.
Color palette: #326FF7 dominant, white and pale blue support, cyan #43D7E8 only as a small accent.
Lighting/mood: calm and orderly with the approved soft contact shadow.
Background: genuinely transparent RGBA, all four corners alpha 0.
Constraints: completed processing must be visible; exactly two or three observations remain; no unsupported score, approval, or risk claim.
Avoid: any text or pseudo-text, letters, numerals, currency symbols, logos, watermark, people, mascots, red alerts, crosses, exclamation marks, locks, 404 imagery, rejection marks, broken objects, downward charts, opaque floor or backdrop.
```

## Concrete character scene

```text
Use case: illustration-story
Asset type: financial B2B product empty-state transparent illustration
Primary request: Full-source retrieval and model assessment completed; no valid <ABSENT MEASURE> was found; this is a positive-leaning sparse-activity state, not an error; periodic reassessment is recommended.
Scene: <ONE RECOGNIZABLE FINANCIAL SETTING WITH A BEGINNING, ACTION, AND RESULT>.
Scene logic: At <RECOGNIZABLE PLACE>, <SUBJECT> performs <PHYSICALLY PLAUSIBLE ACTION> with <BUSINESS OBJECT>, revealing <SPARSE RESULT ON THE SAME WORK SURFACE>.
Prop rule: every object must establish the place, enable the action, or reveal the result; omit unrelated decorative props. Do not add tiny decorative dots, LEDs, badges, pins, particles, sparkles, detached rings, status pips, or geometric accents. Small elements are allowed only when they are the countable sparse business records, and they must be attached to the relevant timeline, institution slot, chart, or application surface.
Character: <OPTIONAL>. If useful, use the recurring man, about 30, short dark hair, calm simplified face, natural adult proportions, cyan #1ED6FF top, dark navy trousers; choose a scene-specific role, pose, facing direction, and action. Otherwise omit people.
Evidence: use the minimum scene-specific cues needed to imply completed evaluation, exactly <ONE OR TWO> observations, substantial orderly unused capacity, and possible later review. Do not force a pipeline or model screen into every scene.
Style: clean flat vector financial illustration, same character construction and medium detail density across the set, front view with slight side angle, soft blue-gray shadow, localized pale-blue abstract ground shape.
Palette: #326FF7 dominant, white and pale blue supporting, #1ED6FF on the shirt and only tiny key accents elsewhere.
Color rendering: clean luminous surfaces; one broad smooth gradient per object; continuous white-to-pale-blue-to-brand-blue transitions; three to five large color masses; no patchy shading, hard color bands, repeated saturated edge strips, dirty gray, violet cast, cyan noise, grain, mottling, speckles, multiple overlapping ground blobs, or excessive blue halos.
Background: transparent outer canvas, all four corners alpha 0.
Avoid: text, pseudo-text, letters, numerals, currency marks, logos, red, warnings, rejection, locks, overdue cues, downward charts, empty boxes, distressed expressions, abstract machinery without a recognizable scene, repeated props or character poses from sibling assets, full opaque background, tiny colored dots on objects, glowing indicator lights, free-standing location pins, floating particles, orbit beads, sparkles, detached markers, miniature badges, decorative micro-elements.
```

## Targeted retry

```text
Preserve the approved subject, composition, object count, production style anchor, camera, palette, lighting, transparency, and every correct detail. Change only this defect: <DEFECT>. Do not add text, symbols, characters, new objects, background scenery, warning cues, indicator dots, pins, particles, badges, sparkles, or any other decorative micro-element.
```

## Four production examples

1. Report archive: orderly folder and evaluated sheets, three data tiles, mostly unused report plane, quiet time orbit.
2. Model evaluation: closed evaluation ring, two input spheres, clear result plate, separate monitoring orbit.
3. Behavior cycle: intact installment/time ring, two occupied behavior nodes, report tile, completion bead.
4. Limit statistics: limit-card pedestal, three retrieved institution tokens, sparse neutral dot plot, future cycle cue.
